Climatologies
=============

Climatologies are utility functions used to help in creating standard atmospheres.


CAIRT Extended Reference Scenarios
---------------------------------

Versioned latitude-band, seasonal, and local-time reference atmospheres.
See the :ref:`ERS example <_example_ers>` for profile comparisons and atmosphere setup.

.. autosummary::
    :toctree: generated/

    sasktran2.climatology.ers


Stratospheric Aerosol Reference Scenarios
----------------------------------------

Paired extinction and particle-size reference cases derived from SAGE III-ISS.
See the :ref:`stratospheric aerosol example <_example_stratospheric_aerosol>`.
